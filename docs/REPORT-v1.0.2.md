## ۲. دیتاست متوازن

`tools/rebalance_knowledge.py` (بازتولیدپذیر، seed ثابت) روی پایگاه دانش اجرا شد:

- **۲۵٬۶۰۳ → ۱۷٬۱۶۶** نمونه، **۳۴ کلاس**، صفر تکرار
- `compose_message`: ۷٬۳۷۲ → **۸۰۴**
- `timer`: ۳۰۹ → **۳۲۱**
- `negative`: ۵۰۶ → **۵۲۹** («کرم ضدآفتاب»، «گرم شدن هوا»، …)
- حداقل هر کلاس **۳۱۱**، حداکثر **۸۱۹**
- گزارش کامل: `ml/dataset_balance_report.json`

> صداقت فنی: «۱۰ میلیون پارامتر» به‌خودی‌خود کیفیت نمی‌سازد. با ~۱۷ هزار نمونه، مدل خطی ۱۰ میلیونی
> عمدتاً خانه‌های صفر دارد و روی دادهٔ تازه بدتر از مدل ۱۹۶٬۶۰۸ بُعدی فعلی عمل می‌کند. پیکربندی
> آزمایشی در `ml/model_config_10m.json` گذاشته شد تا با دادهٔ بیشتر (پیشنهاد: ≥۱۰۰ هزار نمونهٔ
> واقعی و آزمون جدا) سنجیده شود؛ عدد دقت بدون سنجش واقعی گزارش نمی‌شود.

## ۴. ساخت و امضا (گیت‌هاب اکشنز)

- ورک‌فلو: `.github/workflows/apk-release.yml` (job تست بدون Secret، job ساخت فقط با کیستور).
- اسکریپت: `tools/build_apk.sh` — javac → d8 → aapt → zipalign → apksigner (v1+v2+v3) →
  `apksigner verify --print-certs` → مقایسهٔ اثر انگشت گواهی با نسخهٔ ۱.۰.۱ → `SHA256SUMS.txt`.
- اگر اثر انگشت گواهی با `2e3eee11…46b7` یکی نباشد، بیلد **عمداً fail** می‌شود.
- پس از انتشار، لینک دانلود در README، `index.html` و `report/index.html` با
  `tools/update_download_links.sh` به‌روز می‌شود و asset رسمی در Release قرار می‌گیرد.

## ۵. کارهای باقی‌مانده

1. افزودن Secretهای کیستور (بدون آن انتشار ۱.۰.۲ ممکن نیست).
2. اجرای workflow و تأیید خروجی `apksigner verify` (v1/v2/v3 + گواهی یکسان).
3. اصلاح بلوک‌های v2/v3 نسخهٔ ۱.۰.۱ که در بازرسی قبلی معتبر نبودند (فقط با کلید اصلی).
4. جایگزینی انتخاب‌گر رسانه با جریان کامل «انتخاب → دیالوگ سیستم → حذف» (پل بومی آماده است؛ UI انتخاب چندتایی باقی مانده).
