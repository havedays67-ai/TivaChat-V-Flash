## قابلیت‌های نسخه ۱.۰.۰

- تشخیص دستور فارسی با **موتور قواعد محلی** و تطبیق نام/پکیج واقعی برنامه‌های نصب‌شده.
- باز و بستن مسیر اجرای برنامه‌ها، فهرست برنامه‌ها و صفحه اطلاعات هر برنامه.
- گزارش زنده باتری، دما، سلامت، ولتاژ، رم، حافظه، پردازنده، مدل و مدت روشن‌بودن.
- چراغ‌قوه، آلارم، تایمر، جست‌وجوی وب، مسیرهای تنظیمات، ورودی صوتی با موتور سیستم.
- **آیکون شناور** قابل جابه‌جایی، چسبیدن به لبه و محو شدن خودکار.
- سرویس دسترس‌پذیری حداقلی برای بازگشت/خانه/برنامه‌های اخیر؛ محتوای صفحه خوانده نمی‌شود.
- **گاوصندوق رمز** با AES-256-GCM، کلید Android Keystore و تأیید هویت دستگاه.
- تأیید جداگانه برای تماس، پیامک و حذف برنامه؛ بدون روت و بدون تغییر فایل سیستمی.
- تمام پردازش‌ها آفلاین؛ بدون حساب کاربری و بدون تبلیغ.

## محدودیت‌های صادقانه

- نسخه ۱.۰.۰ **مدل زبانی بزرگ (LLM) یا مدل TFLite ندارد**. تشخیص قصد با قواعد فارسی انجام می‌شود. اهداف دقت این صفحه، اهداف طراحی نسخه‌های بعدی هستند.
- اندروید ۱۱+ اجازه پاک‌کردن کش برنامه‌های دیگر را نمی‌دهد؛ اپ به مسیر رسمی تنظیمات هدایت می‌کند.
- ورود خودکار رمز در برنامه‌های دارای `FLAG_SECURE` (مانند برخی بانک‌ها) ممکن نیست.
- ژست «دو ضربه با دو انگشت» در MIUI به مجوز و تنظیمات خاص نیاز دارد؛ جایگزین رسمی در این نسخه، **آیکون شناور** است.
- وای‌فای و بلوتوث از طریق صفحه تنظیمات سیستم تغییر می‌کنند (محدودیت اندروید ۱۰+).

## نصب

1. فایل APK را دانلود کنید.
2. نصب از منابع نامشخص را فقط برای همین فایل به‌طور موقت مجاز کنید.
3. برای آیکون شناور، «نمایش روی برنامه‌های دیگر» و اعلان‌ها را فعال کنید.
4. سرویس دسترس‌پذیری را فقط اگر به اقدامات آن نیاز دارید فعال کنید.
5. در MIUI، Autostart را روشن و محدودیت باتری را بردارید.
6. برای گاوصندوق رمز، قفل صفحه یا اثر انگشت لازم است.

## ساخت از منبع

```bash
# JDK 17 و Android SDK 34 (build-tools 34.0.0) لازم است
aapt2 compile --dir res -o compiled.zip
aapt2 link -o unsigned.apk -I android.jar --manifest AndroidManifest.xml \
  -R compiled.zip --auto-add-overlay -A assets --java gen
javac -encoding UTF-8 -source 11 -target 11 -classpath android.jar -d obj $(find java gen -name '*.java')
d8 --release --min-api 28 --lib android.jar --output dex $(find obj -name '*.class')
# classes.dex را به APK اضافه کنید، سپس:
zipalign -f 4 unsigned.apk aligned.apk
apksigner sign --ks YOUR-KEYSTORE.jks --out TivaChat-V-Flash-v1.0.0.apk aligned.apk
apksigner verify --verbose TivaChat-V-Flash-v1.0.0.apk
```

فقط از کلید و رمز خودتان استفاده کنید. هیچ کلید خصوصی یا رمزی در این مخزن قرار ندارد.
