## در این ساخت چه چیزهایی تغییر کرده؟

### مدل آموزش‌دیده، نه فقط قاعده
- طبقه‌بند **۳٬۹۳۲٬۱۸۰ پارامتری** (hashed n-gram + linear softmax) با کوانتایز INT8.
- **۱۴٬۸۵۸** نمونه آموزش متوازن، **۳٬۱۹۵** نمونه تست قالب‌محور، **۳۲** جمله تازهٔ دست‌نویس.
- **۹۳٫۷۵٪** دقت روی جملات تازه، **۱۰۰٪** دقت روی تست قالب‌محور (داده مصنوعی).
- مدل مولد متن نیست و همهٔ عملیات حساس همچنان با Safety Guard و تأیید کاربر اجرا می‌شوند.
- جزئیات و فایل‌های آموزش: [`ml/`](./ml/README.md)

### رفع باگ باز نشدن پنجره
پنجرهٔ قبلی از پس‌زمینه یک Activity باز می‌کرد و MIUI/اندروید ۱۰+ می‌توانست آن را مسدود کند. اکنون چت **داخل خود سرویس شناور و روی Overlay** باز می‌شود. یک بار ضربه روی آیکون کافی است؛ ضربهٔ دوم روی همان آیکون پنجره را می‌بندد.

### ژست دو انگشتی
- **اندروید ۱۱+**: «دو انگشت، دو ضربه در کل صفحه» از مسیر دسترس‌پذیری (آزمایشی، با هشدار تغییر رفتار لمس).
- **همهٔ نسخه‌ها**: ضربه روی آیکون، دو انگشت روی آیکون، **نوار ژست لبه** (اختیاری؛ دو انگشت + دو ضربه) و دو بار کلید صدا.
- داخل خود اپ هم دو انگشت + دو ضربه در دسترس است.

### آموزش چندمرحله‌ای
- «تلگرام رو باز کن و در پیام های شخصی بنویس سلام»
- «واتساپ باز کن و به مینا بگو فردا می‌بینمت»
برنامه باز می‌شود، گفتگو با نام مخاطب جست‌وجو می‌شود و متن فقط در کادر پیام نوشته می‌شود. اگر نام مخاطب نباشد، پرسیده می‌شود. ارسال خودکار نداریم.

### آموزش و یادگیری شخصی
- تب **آموزش** با نمونه‌های آماده و آمار واقعی مدل.
- امکان یاددادن جملهٔ دلخواه به یک کار؛ روی دستگاه ذخیره می‌شود.
- گزارش زندهٔ باتری، رم، حافظه، دما، برنامه‌ها، چراغ‌قوه، آلارم، تایمر، تماس/پیامک با تأیید و گاوصندوق AES-256-GCM.
- آیکون شناور پس از ری‌استارت در صورت فعال بودن بازمی‌گردد.

## محدودیت‌های صادقانه

- ژست دو انگشتی **روی کل صفحه** بدون دسترس‌پذیری و اندروید ۱۱+ برای یک اپ معمولی ممکن نیست؛ حالت سراسری، لمس معمولی را تغییر می‌دهد و آزمایشی است. نوار لبه و آیکون شناور جایگزین‌های مطمئن‌ترند.
- وقتی گوشی کاملاً خاموش است هیچ اپی نمی‌تواند لمس یا صدا را بگیرد. بازگشت آیکون شناور پس از روشن‌شدن و باز شدن قفل انجام می‌شود.
- نوشتن پیام به دسترس‌پذیری نیاز دارد وآرسال خودکار نیست؛ تغییر رابط تلگرام/واتساپ ممکن است به به‌روزرسانی نیاز داشته باشد.
- پاک‌کردن کش سایر برنامه‌ها (اندروید ۱۱+) و ورود خودکار رمز در برنامه‌های `FLAG_SECURE` پشتیبانی نمی‌شود.
- مدل، یک طبقه‌بند ۲۰ کلاسه است؛ مدل زبانی بزرگ یا TFLite/TensorFlow نیست. ۹۷٫۳٪ وزن‌ها پس از کوانتایز صفر شده‌اند؛ ۱۰۷٬۱۳۹ وزن فعال مانده است. دقت ۱۰۰٪ روی داده مصنوعی قالب‌محور را به همهٔ جملات تعمیم نمی‌دهیم.
- دقت روی ۳۲ جملهٔ تازه ۹۳٫۷۵٪ است؛ این هم یک نمونهٔ کوچک است.

## نصب و مجوزها

1. APK را از لینک بالا دانلود کنید.
2. اگر نسخهٔ قبلی نصب است، همان فایل را نصب کنید (بدون حذف).
3. برای آیکون شناور، «نمایش روی برنامه‌های دیگر» و اعلان‌ها را فعال کنید.
4. برای نوشتن پیام و ژست، سرویس دسترس‌پذیری تیواچت را فعال کنید.
5. در MIUI، Autostart را روشن و محدودیت باتری را بردارید.
6. گاوصندوق نیازمند قفل صفحه/اثر انگشت است.

## هشدار امنیتی

کلید خصوصی امضا در **مخزن خصوصی** نگهداری می‌شود و در این مخزن عمومی نیست. توکن گیت‌هابی که در گفتگو به اشتراک گذاشته شد را باطل (Revoke) کنید و توکن جدید بسازید.

## ساخت

```bash
# JDK 17 + Android SDK 34 / Build-Tools 34.0.0
aapt2 compile --dir res -o compiled.zip
aapt2 link -o unsigned.apk -I android.jar --manifest AndroidManifest.xml \
  -R compiled.zip --auto-add-overlay -A assets --java gen
javac -encoding UTF-8 -source 11 -target 11 -classpath android.jar -d obj $(find java gen -name '*.java')
d8 --release --min-api 28 --lib android.jar --output dex $(find obj -name '*.class')
# add classes.dex, then:
zipalign -f 4 unsigned.apk aligned.apk
apksigner sign --ks YOUR-PRIVATE-KEYSTORE.jks --min-sdk-version 28 \
  --v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true \
  --out TivaChat-V-Flash-v1.0.0.apk aligned.apk
```
